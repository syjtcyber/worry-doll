# 안개숲 걱정인형

걱정을 인형에게 잠시 맡겨두는 웹앱 프로토타입입니다.

## 배포 주소

https://syjtcyber.github.io/worry-doll/

## 초기 설정 순서

- Step 1: GitHub 저장소를 만들고 `index.html`을 업로드한다.
- Step 2: GitHub Pages에서 배포 경로를 `main / root`로 설정한다.
- Step 3: 공개 주소를 열어 입력, 저장, 보내주기 기능을 확인한다.

## 자주 막히는 포인트 FAQ

### Q. GitHub Pages에서 `/docs`와 `/root` 중 무엇을 골라야 하나요?

`index.html`이 저장소 맨 위에 있다면 `/root`를 선택합니다.  
`/docs`는 docs 폴더 안에 사이트 파일을 넣었을 때 사용하는 설정입니다.

### Q. `index.html`을 올렸는데 사이트가 바로 안 바뀝니다.

GitHub Pages 반영에는 시간이 조금 걸릴 수 있습니다.  
1~5분 정도 기다린 뒤 새로고침합니다.

### Q. 앱에 입력한 걱정은 다른 사람에게 보이나요?

아니요. 현재 버전은 서버나 데이터베이스 없이 브라우저 저장소에 기록을 남깁니다.  
같은 기기와 같은 브라우저에서만 기록이 유지됩니다.

### Q. 휴대폰에서 열면 PC에서 쓴 기록이 안 보입니다.

정상입니다. 현재 버전은 기기 간 동기화를 지원하지 않습니다.

### Q. 수정한 파일을 다시 올리면 주소가 바뀌나요?

아니요. 기존 저장소의 `index.html`만 교체하면 사이트 주소는 그대로 유지됩니다.인형 웹앱 프로토타입
